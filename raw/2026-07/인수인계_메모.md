지금 알림을 보내는 봇(`@wanggi_dashboard_bot`)은 원 소유자 개인 계정으로 만든 것입니다. 앞으로 이 업무를 완전히 넘겨받으면:
1. 텔레그램에서 `@BotFather`에게 `/newbot`으로 새 봇 생성 (실무자 명의)
2. 새로 받은 토큰으로 저장소 Settings → Secrets and variables → Actions의 `TELEGRAM_BOT_TOKEN` 값 교체
3. 새 봇을 "단양공장전력관리" 그룹에 초대 + 관리자 권한 부여, 기존 봇은 그룹에서 제외

- Settings → 맨 아래 Danger Zone → Transfer ownership
- **주의:** 이전되면 저장소 URL과 GitHub Pages 대시보드 주소가 `rlwhd3961-1.github.io/daily-power-dashboard/`로 바뀝니다. 텔레그램 그룹에 기존 링크가 공유되어 있다면 새 링크로 다시 공지해야 합니다.
