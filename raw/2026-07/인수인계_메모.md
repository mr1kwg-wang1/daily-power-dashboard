## 5. VS Code로 git 운영하는 방법 (위 3번의 실제 조작법)

VS Code + Claude Code 설치, 저장소 클론까지는 이미 되어 있다는 전제입니다. 매일 CSV 파싱 후 `daily_data.json`이 바뀐 상태에서, commit·push는 아래 세 가지 방법 중 편한 걸로 하면 됩니다.

### 방법 A — Source Control 패널 (마우스 클릭만, 가장 쉬움)

1. VS Code 왼쪽 사이드바에서 **가지 나뉜 모양 아이콘**(Source Control) 클릭
2. 변경된 파일 목록(`daily_data.json` 등)이 보임
3. **Changes** 옆 **+** 아이콘 클릭 → 전체 스테이징 (또는 파일 하나씩 + 클릭)
4. 위쪽 메시지 입력창에 커밋 메시지 입력 (예: `7월 15일 일보 반영`)
5. **✓ Commit** 버튼 클릭
6. 하단 상태바 또는 패널 상단의 **동기화(순환 화살표) 아이콘** 클릭 → 이게 push까지 한 번에 처리함

→ 명령어를 하나도 안 쳐도 되는 방법이라 이걸 추천합니다.

### 방법 B — VS Code 내장 터미널 (명령어로)

1. 상단 메뉴 **Terminal → New Terminal**
2. 아래 세 줄 순서대로 입력·Enter:
   ```
   git add .
   git commit -m "7월 15일 일보 반영"
   git push
   ```

### 방법 C — Claude Code에게 그냥 시키기

VS Code 안 Claude Code 대화창에 이렇게 입력하면 알아서 처리합니다:
> "오늘 CSV 파싱해서 daily_data.json 갱신하고, commit·push까지 해줘"

push가 끝나면(방법 A/B/C 무엇이든) `main` 브랜치의 `daily_data.json`이 바뀐 거라, GitHub Actions가 자동으로 돌아서 텔레그램 알림이 나갑니다.
